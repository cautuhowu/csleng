**Csleng** (/siːɛslɛŋ/) is a lightweight, low-level ASCII console game engine for Python on Windows.

Inspired by retro terminal interfaces, Csleng utilizes pure Win32 API calls via ctypes to deliver high-performance rendering, zero-flicker double-buffering, asynchronous sound playback, and real-time keyboard handling—all with zero external dependencies.

Csleng is open source under the MIT License and free to use. Let's bring retro ASCII games back to life!

Also, this project is developed by one person. If you find it useful or cool, please consider giving it a star on GitHub!
